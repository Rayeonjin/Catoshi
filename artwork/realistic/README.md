# 실사풍 삼색 고양이 아트 소스

`calico-poses.png`, `calico-motion.png`, `calico-sitting.png`는 Catoshi의 실사풍 고양이 포즈를 위해 OpenAI imagegen으로 생성한 투명 배경 원본입니다. 앞의 두 이미지는 4열 × 3행, 마지막 이미지는 한 줄에 4개 자세를 담습니다. 사진처럼 보이도록 생성한 이미지이며 실제 반려묘의 사진은 아닙니다.

메뉴바용 1624 × 40px 아틀라스는 저장소 최상위 폴더에서 다음 명령으로 재생성합니다.

```bash
swift scripts/build_realistic_atlas.swift
```

포즈 프롬프트 요약: 투명 배경의 동일한 성체 삼색 단모 고양이, 실제 고양이 해부학과 자연스러운 털결·광원, 서로 겹치지 않는 전신 포즈. 첫 시트는 기본·앉기·식빵·기지개·그루밍·잠·기쁨·놀람·걷기 4단계, 둘째 시트는 달리기·우다다·도망·방향 전환·눈 깜박임, 셋째 시트는 앉아서 눈 깜박이기·귀 움직이기·꼬리 움직이기입니다. 글자·소품·배경·만화풍 표현은 사용하지 않았습니다.
