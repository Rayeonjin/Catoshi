- `demo.gif`: 약 12초(36프레임)의 메뉴바 고양이·시장·국내 거래소·공유 카드 소개.
- `menu-bar.png`, `market.png`, `kr-exchanges.png`, `share-card.png`: 같은 버전의 네이티브 UI 컴포넌트와 가상 데이터로 만든 문서 이미지.

**이미지의 숫자는 가상 예시이며 실제 시장 데이터가 아닙니다.** 화면에 이 사실을 표시합니다. 실제 앱 실행·실시간 API·실사용 성과를 입증하는 자료로 사용하지 않습니다. 사용자 화면·알림·계정·개인 파일은 포함하지 않았습니다.

시각 자료는 실제 SwiftUI/AppKit 컴포넌트와 프로젝트 고양이 자산을 사용했습니다. 공개 앱에는 별도 데모 모드를 추가하지 않았습니다. 생성 도구와 규격별 렌더 검증물은 비공개 운영 폴더에 보관합니다.
