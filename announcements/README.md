# 공지 원고

텔레그램에 게시할 완성 원고를 `telegram/v버전.txt`에 보관합니다. 예: [v2.16.17](telegram/v2.16.17.txt).

파일 내용이 그대로 공지됩니다. 제목·변경 사항·설치 안내·릴리스 링크·Fairy 링크까지 파일 안에 작성합니다. 일반 텍스트 형식이며 Markdown 문법은 변환하지 않습니다. 파일 끝의 빈 줄만 제거합니다.

## 새 버전 공지 순서

1. 이전 원고를 복사해 `telegram/v새버전.txt`를 만듭니다.
2. 제목, 변경 사항, 릴리스 링크를 새 버전에 맞게 작성합니다. `bash setup.sh` 설치 안내와 `https://fairy.hada.io/@catoshi` 링크를 포함합니다.
3. 원고를 먼저 `main`에 커밋·푸시한 뒤 해당 버전의 정식 릴리스를 게시합니다.
4. 자동 공지는 실행 시 체크아웃한 `main`의 해당 버전 파일을 사용합니다. 릴리스 본문을 대신 전송하지 않습니다.
5. 해당 버전의 자동 실행이 끝날 때까지 확인하고, 실제 게시 단계의 성공과 메시지 ID를 확인합니다. 미리보기 성공만으로 전송 완료라고 보고하지 않습니다.

공지 작성과 전송 확인은 매 배포의 필수 완료 조건입니다. [배포 체크리스트](../docs/RELEASING.md)를 함께 따릅니다.

원고가 없거나 비어 있거나 4,096 UTF-16 단위를 초과하거나 해당 버전의 릴리스 링크·설치 안내·후원 링크가 없으면 전송을 중단합니다. 긴 원고를 임의로 자르지 않습니다.

파일 추가·수정만으로 공지가 게시되지는 않습니다. 이미 게시한 원고를 수정해도 기존 텔레그램 메시지는 바뀌지 않습니다. 수동 전송 전에는 중복 게시 여부를 확인하세요. 이 폴더는 공개 저장소에 포함되므로 공개할 내용만 작성합니다.

봇 생성·Secrets 등록·미리보기와 실제 전송 방법은 [자동 공지 설정 가이드](../docs/TELEGRAM_ANNOUNCEMENTS.md)를 참고하세요.
