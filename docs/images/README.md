- `catoshi-menubar.gif`: README 첫 화면의 12초·90프레임 반복 애니메이션. 화면 상단에 Apple·Finder 메뉴, 현재 앱의 네이티브 Catoshi 상태 항목, 시스템 아이콘을 배치하고 그 아래에 직접 만든 추상 배경화면을 더한 macOS 데스크톱 구성 예시입니다. 고양이가 걷고, 방향을 바꾸고, 식빵 자세로 쉬는 동안 하나의 장면 전체를 같은 배율로 서서히 확대해 Catoshi에 다가갔다가 돌아옵니다. 별도의 확대 상자는 없습니다. 동작 순서를 지정한 예시이며, 사용자의 실제 Mac 화면이나 앱 실행을 녹화한 영상은 아닙니다. 숫자는 고정된 가상 데이터입니다.
- `catoshi-menubar.png`: 같은 데스크톱 구성의 정지 장면. 화면 위쪽 메뉴바에서 고양이와 시세가 놓인 위치를 보여 줍니다.
- `demo.gif`: 보조 자료인 **전체 화면 둘러보기**. 약 28초, 메뉴바·시세 패널·표시항목 설정·고양이 꾸미기·펼친 시장 반응·시장·국내 거래소·공유 카드 8장면.
- `menu-bar.png`: 실제 `StatusBarContentView` 전체와 같은 `StatusBarSegment`의 항목별 확대. 미니 차트·24시간 변동·고양이·연결 상태 점을 표시합니다.
- `price-panel.png`: 실제 `MarketPopover`의 시세 탭. 고양이 꾸미기·표시항목 설정 진입 버튼을 함께 보여 줍니다.
- `display-settings.png`: 실제 500pt 표시항목 설정. 가격·변동률·미니 차트와 색상 설정. 미리보기는 앱과 같은 가로 스크롤 구성입니다.

- `cat-reactions.png`: 같은 고양이 설정의 급등·급락 반응을 펼친 상태. 민감도·쿨다운까지 전체 높이를 담습니다.
- `market.png`, `kr-exchanges.png`, `share-card.png`: 같은 버전의 네이티브 UI 컴포넌트와 가상 데이터로 만든 기존 문서 이미지.
- `catoshi-app-icon.png`: 프로젝트 앱 아이콘.

**이미지의 숫자는 가상 예시이며 실제 시장 데이터가 아닙니다.** 이미지 또는 인접 캡션에 이 사실을 표시합니다. 미니 차트 기본값은 꺼짐이며 문서 예시에서는 세 항목을 모두 켰습니다. 실제 앱 실행·실시간 API·실사용 성과를 입증하는 자료로 사용하지 않습니다. 사용자 화면·알림·계정·개인 파일은 포함하지 않았습니다.

시각 자료는 실제 SwiftUI/AppKit 컴포넌트와 프로젝트 고양이 자산을 사용했습니다. 첫 화면의 애니메이션과 정지 이미지에서 Catoshi 상태 항목은 앱 UI를 렌더링한 것이며, Apple·Finder 메뉴와 시스템 아이콘·배경화면은 데스크톱 맥락을 보여 주기 위해 재현한 구성입니다. 다른 설명 이미지에는 제목·여백과 항목별 확대를 별도로 배치했습니다.

고양이 애니메이션은 앱의 걷기 보폭·프레임 속도에 맞추고, 동작 사이의 긴 대기 시간을 예시 순서로 구성했습니다. 카메라 이동은 장면 전체에 적용한 문서용 연출이며, 앱의 메뉴바 크기나 고양이 이동 속도를 변경한 기능을 뜻하지 않습니다. 공개 앱에는 데모 모드나 설정 변경을 추가하지 않았습니다. 생성 도구는 별도 번들 ID·휘발성 예시 설정·중지된 백그라운드 작업으로 동작합니다. 시장 반응을 펼친 이미지는 비공개 생성용 소스 사본에서 기존 펼침 상태의 초기값만 선택했습니다. 생성 도구와 검수 기록은 비공개 운영 폴더에 보관합니다.
