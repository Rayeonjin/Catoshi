- `catoshi-app-icon.png`: 프로젝트 앱 아이콘.

**이미지의 숫자는 가상 예시이며 실제 시장 데이터가 아닙니다.** 화면에 이 사실을 표시합니다. 미니 차트 기본값은 꺼짐이며 문서 예시에서는 세 항목을 모두 켰습니다. 실제 앱 실행·실시간 API·실사용 성과를 입증하는 자료로 사용하지 않습니다. 사용자 화면·알림·계정·개인 파일은 포함하지 않았습니다.

시각 자료는 실제 SwiftUI/AppKit 컴포넌트와 프로젝트 고양이 자산을 사용했습니다. 설명용 제목·여백과 메뉴바 확대를 별도로 배치했습니다. 고양이 애니메이션은 앱의 걷기 보폭·프레임 속도에 맞추고, 동작 사이의 긴 대기 시간을 예시 순서로 구성했습니다. 확대 화면은 고양이가 잘 보이도록 같은 장면을 공간적으로 확대했으며, 앱의 메뉴바 크기나 고양이 이동 속도를 변경한 기능을 뜻하지 않습니다. 공개 앱에는 데모 모드나 설정 변경을 추가하지 않았습니다. 생성 도구는 별도 번들 ID·휘발성 예시 설정·중지된 백그라운드 작업으로 동작합니다. 시장 반응을 펼친 이미지는 비공개 생성용 소스 사본에서 기존 펼침 상태의 초기값만 선택했습니다. 생성 도구와 검수 기록은 비공개 운영 폴더에 보관합니다.
